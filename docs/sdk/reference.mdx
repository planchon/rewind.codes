Every call takes an `AbortSignal` as `signal`. The types are those of the API, generated from its
[OpenAPI document](https://github.com/planchon/rewind.codes/blob/main/api/openapi.json) and exported under their names.

| Resource | Calls |
| --- | --- |
| `rewind.actionSets` | `create` (`mcp`, `apis` from OpenAPI documents, `harness`, `http`, each server's `auth`; `workflows` pins the organization's workflows, `base` derives from an action set), `declarations`, `search` |
| `rewind.workflows` | `check` (type-checks code), `test` (tests in virtual time, and a workflow's suite), `create` (a namespace's or the organization's, with `tests`), `list` and `listAll` (the latest version of each, with their counts), `get` (by id or name, its versions, suite and source), `update` (name, description), `createVersion` and `addTests` (through the gate, with `replace` and `retire`), `promote`, `fork`, `pull`, `record` (tests from past runs) |
| `rewind.tests` | `get`: a stored test by its digest |
| `rewind.runs` | `start` (`code`, or a `workflow`), `get`, `list` and `listAll` (`q`, `sort`, `workflow`, `startedBy`…), `stats`, `failures`, `signal`, `cancel`, `fork`, `transcript`, `event`, `events`, `export` (`as: "cassette"`), `release`, `giveUp`, `delete`; `start` and `fork` take `secrets` |
| `rewind.calls` | `stream` (the [call stream](/sdk/harness-actions#the-call-stream): `actionSet`, `actions`, `namespace`, `slots`, `worker`), `defer`, `complete`, `fail`, `approve`, `reject`: calls at the level of the API |
| `rewind.approvals` | `pending(run)`, `args`, `approve`, `reject` |
| `rewind.payloads` | `get(digest, { run })`: a value left out above 256 KiB, read through the run that holds it |
| `rewind.namespaces` | `list` and `listAll` (`prefix`, `above`, `order`, `month`), `get`, `put` (exceptions), `rename`, `delete`, `alerts` |
| `rewind.namespaces.secrets` | `list`, `put`, `delete`, `usage`: an end user's own [secrets](/sdk/secrets), used as `ns/<name>` |
| `rewind.namespaces.defaults` | `get`, `put`: the default limits of every end user, and the ceiling |
| `rewind.namespaces.tokens` | `create` (its answer holds the token, once), `revoke`, `revokeAll` |
| `rewind.tokenKeys` | `create`, `list`, `delete`: the keys your backend signs end users' tokens with |
| `rewind.secrets` | `list`, `put`, `delete`, `usage`: the organization's [secrets](/sdk/secrets), used as `org/<name>` |
| `rewind.signingKeys` | `list` (with the `issuer` and the `jwksUrl`), `rotate`, `jwks`: the keys Rewind [signs its calls](/sdk/signed-calls) with |
| `rewind.subscriptions` | `create` (its answer holds the secret, once), `list`, `delete` |
| `rewind.webhooks` | `verify` |
| `rewind.actions` | `stats`: latency, errors and redeliveries per action, of one end user or the organization, over a window |
| `rewind.apiKeys` | `create`, `revoke` |
| `rewind.server` | `info` (the version, the epochs, the node that answered, the deployment's partitions and nodes), `stop` |

| Method | Returns |
| --- | --- |
| `rewind.namespace(name)` | The same client, acting for one end user |
| `rewind.worker(options)` | A [worker](/sdk/harness-actions) of harness actions, started |
| `rewind.agentTools(options)` | The [agent tools](/sdk/agent-tools) |

## The HTTP API

The SDK is a client of the HTTP API `/v1`, which any language can call. Requests carry
`Authorization: Bearer <key or token>`, and `Rewind-Namespace: <end user>` to act for an end user with a key. The full
contract is the [OpenAPI document](https://github.com/planchon/rewind.codes/blob/main/api/openapi.json).

```bash
curl https://api.rewind.codes/v1/runs \
  -H "Authorization: Bearer $REWIND_API_KEY" \
  -H "Rewind-Namespace: user_ada" \
  -H "Idempotency-Key: call_8f2c" \
  -H "Content-Type: application/json" \
  -d '{"code": "export default async function main() { return 42 }", "wait": "30s"}'
```
