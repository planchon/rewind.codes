---
title: "Webhooks"
description: "Receive signed webhooks: a run completed, failed or waits; an action changed; a secret was refused or is missing; an end user nears a limit."
---

Rewind posts a webhook to your harness when something happens to a run, so it can resume a conversation when a long
run ends, show a pending approval, or warn about a quota. Webhooks follow
[Standard Webhooks](https://www.standardwebhooks.com): an HMAC-SHA256 signature over `{id}.{timestamp}.{body}`, with
5 minutes of tolerance on the timestamp.

## Subscribe

```ts
const subscription = await rewind.subscriptions.create({
  url: "https://harness.example.com/rewind-webhooks",
  types: ["run.completed", "run.failed", "run.waiting", "quota.alert"], // every type when empty
  labels: { agent: "triage" }, // optional: only runs carrying these labels
});

subscription.secret; // whsec_…: only in this answer, keep it
```

Subscriptions belong to your organization: one receives the webhooks of every end user, each naming its namespace.
Webhooks are posted to public `https://` URLs.

## Verify and handle

Pass the body exactly as received, before any JSON parsing. Answer fast, then work. A webhook your endpoint did not
accept is posted again with backoff, with the same `webhook-id` header: deduplicate on it.

<CodeGroup>
```ts Express
import express from "express";
import { verifyWebhook, WebhookVerificationFailed } from "@rewind.codes/sdk";

const app = express();

app.post("/rewind-webhooks", express.raw({ type: "application/json" }), (req, res) => {
  let webhook;
  try {
    webhook = verifyWebhook(req.body, req.headers, process.env.REWIND_WEBHOOK_SECRET!);
  } catch (error) {
    if (error instanceof WebhookVerificationFailed) return res.sendStatus(400);
    throw error;
  }
  res.sendStatus(204);
  if (alreadySeen(req.headers["webhook-id"])) return;

  if (webhook.type === "run.completed") resumeConversation(webhook.data.run); // webhook.data.run.namespace: the end user
  if (webhook.type === "run.waiting") showWhatItWaitsFor(webhook.data.run.waitingFor);
  if (webhook.type === "quota.alert") warnCustomer(webhook.data); // namespace (null: the ceiling), quota, threshold
});
```

```ts Node http
import { createServer } from "node:http";
import { verifyWebhook, WebhookVerificationFailed, type Webhook } from "@rewind.codes/sdk";

createServer(async (req, res) => {
  const chunks: Buffer[] = [];
  for await (const chunk of req) chunks.push(chunk as Buffer);

  let webhook: Webhook;
  try {
    webhook = verifyWebhook(Buffer.concat(chunks), req.headers, secret);
  } catch (error) {
    if (error instanceof WebhookVerificationFailed) return void res.writeHead(400).end();
    throw error;
  }
  res.writeHead(204).end();
  handle(webhook);
}).listen(3000);
```
</CodeGroup>

`webhook.type` narrows `webhook.data` to the right shape. The complete program, with a run that waits and completes, is
in [`examples/webhooks`](https://github.com/planchon/rewind.codes/tree/main/examples/webhooks).

## Types

| Type | When | `data` |
| --- | --- | --- |
| `run.completed` | The run completed | `run`, with its `output` |
| `run.failed` | The workflow's code failed | `run`, with its `error` |
| `run.cancelled` | The run ended cancelled | `run` |
| `run.aborted` | The engine ended the run: a limit, a cleanup past its grace step | `run`, with its `abort` |
| `run.waiting` | A step left the run waiting on the outside world: a signal, an approval, a harness action, a parked call. A timer alone sends nothing | `run`, with its `waitingFor` |
| `run.quarantined` | The run was quarantined: release it or give it up | `run`, with its `quarantine` |
| `action.schema_changed` | A call was parked because the action's schema changed during the run | The run, the call and the change |
| `secret.expired` | A call was parked: its server refused the secret or the signature (`reason: "refused"`), or the secret the run uses no longer exists (`"missing"`, nothing was sent). Put the [secret](/sdk/secrets) again, or approve a refused signed call | The run, the call, the server, the `secret` the run uses (`org/…`, `ns/…`; absent for a signed call), the `reason` and the server's answer |
| `quota.alert` | An end user, or your organization, crossed 80 % or 100 % of a limit | `namespace` (`null` for the ceiling), `quota`, `threshold`, `used`, `limit`, `period` |

Every webhook about a run carries the run's state as the step left it, its `namespace` and its `labels`.

## Manage subscriptions

```ts
const subscriptions = await rewind.subscriptions.list();
await rewind.subscriptions.delete(subscription.id);
```
