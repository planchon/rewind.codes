The [`examples/`](https://github.com/planchon/rewind.codes/tree/main/examples) directory of the repository holds one
program per subject. Each `index.ts` is harness code you run; each `scripts/*.ts` is what a model would write, and runs in
Rewind's sandbox.

## Run them

Node 22.18 or later, which runs TypeScript as is, and pnpm.

```bash
git clone https://github.com/planchon/rewind.codes.git
cd rewind.codes/examples
pnpm install
cp .env.example .env    # REWIND_URL, REWIND_API_KEY, and a model's key for agent/
pnpm quickstart         # or: pnpm human-approval, pnpm workflows, pnpm testing…
```

The scripts reach `api.github.com` without credentials: GitHub allows 60 such requests an hour. `pnpm webhooks` needs
a URL Rewind can deliver to: a public `https://` URL (a tunnel to your machine, in `WEBHOOK_URL`), or a server of your
own started with `--allow-private-webhooks`.
