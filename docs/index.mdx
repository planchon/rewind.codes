title: "What is Rewind"
description: "Your model writes one TypeScript workflow that calls your actions. Rewind runs it durably, and records every step in its history."
---

Rewind runs durable workflows written by a model, built for the developers of agent harnesses. Instead of calling your
tools one at a time through the conversation, the model writes a **workflow**: TypeScript code that calls your
**actions**, the tools of your MCP servers, the operations of your APIs, your own functions and other workflows.
Rewind type-checks the code against your actions, runs it in a deterministic V8 sandbox, and records every interaction
with the outside world in the run's **history**.

```ts The model writes this
import { github, slack } from "rewind:actions";
import { sleep, signal } from "rewind";

export default async function main(input: { repo: string }) {
  const issues = await github.list_issues({ repo: input.repo, state: "open" });
  const stale = issues.filter((i) => Date.now() - Date.parse(i.updated_at) > 30 * 86_400_000);

  await slack.post_message({ channel: "#triage", text: `${stale.length} stale issues in ${input.repo}` });

  const decision = await signal<{ close: boolean }>("approval", { timeout: "3d" });
  if (!decision?.close) return { closed: 0 };

  await Promise.all(stale.map((i) => github.close_issue({ repo: input.repo, number: i.number })));

  await sleep("10d");
  const reopened = await github.list_issues({ repo: input.repo, state: "open", labels: "reopened" });
  return { closed: stale.length, reopened: reopened.length };
}
```

One workflow, one tool call from the model's point of view. It lists the issues, filters them in code, waits three days
for a human, closes the stale ones in parallel, sleeps ten days and checks again. Only the last line comes back into
the model's context.

## Everything comes from the history

Every call, timer, signal and log line is an event of the run's history, linked to the line of TypeScript that caused
it. The history is the only source of truth: every feature of Rewind is derived from it.

## Who it is for

Rewind is for teams that build agents: a coding agent, a support agent, an operations agent, any product where a model
acts for your users. Your harness keeps its model loop and its prompts. It adds Rewind through the
[TypeScript SDK](/sdk/overview) (or the HTTP API `/v1`), and gives the model a few ready-made tools: `run_workflow`,
`get_run`, `signal_run`, `retry_run` and others.

Each of your users gets a [namespace](/concepts/end-users): their runs, workflows, secrets and quotas, isolated from
everyone else's.
