notes.create_note({ note: { title: string, body?: string, pinned?: boolean } }) → { id: string } · Create a note.
notes.list_tags() → ToolContent · Every tag in use.
notes.search_notes({ query: string, limit?: number, sort?: "relevance" | "newest" | "oldest", tags?: string[] | null }) → { result: { body: string | null, created: string, id: string, tags: string[], title: string }[] } · Search notes by text and tags.
