rewind

Serverless durable workflows, made for the agentic era.

Your agents write a workflow for each user and each task. Rewind runs every one of them for as long as it takes, with no server to manage, nothing lost in a crash, and every step on the record.

Software used to be written once, for everyone. Now it's written every time, for every one.

Agents write that code, and it has to wait for days, survive failures and stay safe. The tools we have each cover a part of it.

A sandbox runs it, then forgets.

Code runs while the box is up. When the box stops, the work stops: nothing waits three days for an answer, nothing resumes after a crash.

A workflow engine needs engineers.

It is durable, but built for code a team writes, reviews and deploys. That code must stay deterministic and be versioned by hand, rules an agent can't be trusted to keep.

Rewind is both.

Durable workflows for code an agent wrote a second ago. It deploys in one call, runs isolated, and the runtime itself keeps every run deterministic.

Durable

Work that outlives the conversation.

The chat ends, the user closes the app, a server restarts. The workflow keeps going until its job is done, for days or for months.

Durable by default

A workflow waits days for a reply, sleeps until March, survives crashes and deploys, and resumes exactly where it stopped. No step is ever done twice.

Hover a span

Every step on the record

The journal that makes a run durable also makes it observable. Every tool call, wait, answer and log is recorded and tied to the line that caused it, traces go to OpenTelemetry, and the dashboard shows every run of every user.

Agent-ready

Your agent is the developer.

It writes the workflow, checks it against your tools, tests it, ships it and fixes it, with tools made for it. Nobody builds or deploys anything.

Deployed in one call

The agent writes the workflow and runs it with a single tool call. No build, no pipeline, no server: the workflow exists the moment the agent writes it.

Every tool, from code

One workflow calls your MCP servers and your agent's own functions: a person for an approval, another model, a sub-agent. Dozens of calls, not dozens of turns.

Re-testable by default

When generated code has a bug, the agent fixes it and tests again. Past runs replay as tests, time is virtual so ten days pass in milliseconds, and a fixed run resumes without repeating a single call.

Pick a format, or unplug Rewind

Plugs into your harness

Ready-made agent tools in the Anthropic and OpenAI formats, and typed declarations of your tools for the prompt. Your agent keeps its model, its loop and its tools.

Scalable

All the code your agents write.

One workflow per user and per task adds up fast. Rewind runs every one of them on workers that scale out with the load, and you never run a server.

Click an isolate to break out

Isolated on V8

Each workflow runs in its own V8 isolate, on workers built with Deno's crates. No file system, no network unless you allow it, no access but the tools you grant.
